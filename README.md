Rock Paper Scissors Game 🎮
A simple console-based Rock Paper Scissors game developed in Python.

🎯 About the Project
This project is a beginner-friendly Python console game where the player competes against the computer in Rock Paper Scissors.

The project demonstrates basic Python programming concepts and interactive console input/output.

✨ Features
Rock, Paper, Scissors gameplay
Player input
Computer-generated choices
Game result calculation
Interactive console experience
🛠️ Technologies Used
Python
Python Console
🚀 How to Run
Install Python.
Download or clone this repository.
Open the project folder in a terminal.
Run:
python "Rock,paper & scissor game.py"
